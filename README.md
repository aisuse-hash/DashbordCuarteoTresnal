# Dashboard Cuarteo

Para publicar en GitHub Pages:

1. Dejá este archivo `index.html` en la raíz del repositorio.
2. En GitHub: Settings > Pages.
3. Source: Deploy from a branch.
4. Branch: `main` y carpeta `/ (root)`.
5. Guardá los cambios.

El dashboard contiene los datos históricos embebidos en el propio `index.html`,
por lo que no necesita archivos JSON adicionales para mostrar la información inicial.
